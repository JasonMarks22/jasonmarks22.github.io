# jasonmarks22.github.io

Personal portfolio for Jason Marks. Live at **https://jasonmarks22.github.io**

Plain HTML, CSS and JavaScript on GitHub Pages. No build step: edit a file, push to `main`, and the site updates in about a minute.

## How to update the site

| I want to… | Edit |
| --- | --- |
| Add, change, or reorder a project | `assets/projects.js`: copy a project block and fill it in (instructions at the top of the file) |
| Add project screenshots | Put images in `assets/` and list them in that project's `shots` |
| Change the About text, goals, or "Looking for" | `index.html`, section `id="about"` |
| Update coursework | `index.html`, section `id="coursework"` |
| Update experience | `index.html`, section `id="experience"` |
| Update skills | `index.html`, section `id="stack"` |
| Replace the résumé | Overwrite `Jason_Marks_Resume.pdf` (keep the same file name) |
| Change the headshot | Replace `assets/jason.jpg` (square image) |

The **Repositories** section and the terminal's `projects` command update automatically: repos come from GitHub, and projects come from `assets/projects.js`.

## Files
